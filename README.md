# About Me
Hi, I'm Petar. I mostly do backend work, usually in C# or Java. I've always been curious about what actually happens between hitting save and seeing the thing run, so I tend to end up digging through build setups and the glue code between services more than I probably should. I also like figuring out how to show messy, connected data in a way that's actually readable.

Right now I'm doing my Master's in IT at the Faculty of Sciences in Novi Sad.

**What I'm messing with lately**

Event sourcing, mostly to see how far you can push it before it gets painful

Some ML and AI stuff on the side

**Tech I use**

Backend: C#, ASP.NET Core, Java (Spring Boot), NestJS

Frontend: Angular, React, Next.js

Database: MySQL, PostgreSQL

Other: Docker, Git, Linux, Azure

**Outside of coding**

Usually picking up some new hobby, or getting sidetracked by a tool I found and now have to try.
